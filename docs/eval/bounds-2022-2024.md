## 重跑

```bash
python run_backtest.py --bounds --fees default --settlement t2 --premium-basis same_day
```

阶段 F 之后，`--bounds` 默认使用真实条款和决策时可见的净值；上面的参数恢复本报告的假设（统一 1.5%、统一 T+2、T 日净值），结果与本报告逐字节相同。阶段 F 的结果见 [phase-f-sensitivity.md](phase-f-sensitivity.md)。
